# Описание
На большинстве сайтов, где можно читать мангу онлайн, имеется возможность вручную открыть изображение страницы в новом окне и скачать его себе на устройство. Полезно, если нужна определенная страница или есть желание прочитать главу/том/мангу офлайн. При желании можно загрузить себе любую мангу любой продолжительности и объема, пожертвова при этом свои временем на выполнение однотипных действий. Желание автоматизировать этот процесс сподвигло на написание данной программы. На данный момент она сыровата, но в планах уже есть некоторое функциональное наполнение.

Основой данной программы является библиотека Requests для Python.
